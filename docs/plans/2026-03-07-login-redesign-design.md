# 学生登录页重构设计

## 背景

Linear issue `YEE-18` 要求将学生登录页标题改为“内蒙古师范大学”，并基于 frontend design 思路重构页面视觉。

当前页面已具备完整登录流程，问题集中在品牌识别弱、信息层级普通、登录区视觉张力不足。

## 目标

- 将主品牌标题改为“内蒙古师范大学”。
- 保持现有登录逻辑、路由跳转、错误提示不变。
- 仅重构登录页结构与样式，不影响其他业务页面。

## 方案

采用“校园品牌首页式登录”：

- 左侧作为品牌展示区，突出学校名称、平台定位、使用流程与数据化特征。
- 右侧作为登录区，强化标题、字段说明、状态提示和操作按钮。
- 使用更明确的背景层次、玻璃感面板和轻量动画，提升首屏质感。

## 约束

- 不新增第三方依赖。
- 尽量把样式收敛在登录页专用 class，避免波及全局。
- 保持移动端和桌面端都可正常使用。

## 验证

- `pnpm run check`
- `pnpm run build`
